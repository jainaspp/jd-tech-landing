Microsoft Designer 3 步：一句出賀卡

一句出賀卡

最後核實：2026-10-03

跟 Reel 用 Microsoft Designer 網頁版整賀卡：designer.microsoft.com 登入 → 主頁揀 Greeting cards → Explore ideas 或自寫場合描述 → Generate → Download 或 Edit text。附官方免費／訂閱提醒同 personal non-commercial 授權、OneDrive 儲存說明。

Reel 一句講晒：一句出賀卡

你會學到

  • 點樣喺 designer.microsoft.com 用個人 Microsoft 帳戶開 Greeting cards
  • Explore ideas／自寫場合同收件人描述後撳 Generate 出賀卡選項
  • Download 存相或 Edit text 改內文，同 AI 圖文字可能錯字要先核對

開始前準備

  • 電腦瀏覽器開 designer.microsoft.com（免費 Microsoft 帳戶可試）
  • 想清楚場合同收件人（例如朋友生日、節日祝賀）
  • 個人帳戶授權係 personal, non-commercial；商業用途要另查條款

3 步做法

  1. 開 Designer 揀 Greeting cards：瀏覽器開 designer.microsoft.com，用免費 Microsoft 帳戶登入。主頁揀 Greeting cards（賀卡）。

    官方：Visit the web app at designer.microsoft.com；需 sign in with a Microsoft account（免費登記）。

    官方例子包括 personalized greeting card、節日邀請、祝賀社交帖。成日要臨時整生日／節日卡最啱呢步。

  2. 打描述再 Generate：用 Explore ideas 揀例子，或者自己打場合同收件人描述。撳 Generate，AI 出幾張賀卡選項。

    官方 Greeting cards：Use Explore ideas 揀例子預載提示，再改成你嘅收件人同場合；或者自己寫 description。

    Select Generate，AI 會按你輸入建立賀卡選項。官方例子：生日卡、節日卡、祝賀社交帖都可以由一句描述生成。

  3. Download 或改字：揀中意嗰張，撳 Download 存相；想改內文就撳 Edit text。檔案會入 My creations；上載／專案計入 Microsoft 雲端儲存額度。

    官方：Download your results as is 或 select Edit text to make changes；Find your cards in My creations。

    官方寫明：AI 生成圖入面嘅文字可能唔係你要求嘅語言，或者有拼寫錯誤——睇完先再送出。

    官方：Designer 免費可用；想更頻密建立可能需要訂閱。額度以帳戶畫面為準——本站唔報死數字。授權為 personal, non-commercial。

    上載相會入 OneDrive；專案可喺 My projects 刪（官方提醒 Designer 無回收筒，刪咗唔可以復原）。

可抄 Prompt

賀卡描述例子

給阿明的生日卡，溫暖友善，多謝佢成日幫手
（或英文：Birthday card for Ming, warm and friendly, thanks for always helping）
場合＋收件人寫清楚；可用 Explore ideas 先揀模板再改。

常見錯誤／注意事項

  • 當商業授權：官方寫明 personal, non-commercial；商業用途要另查條款。
  • 唔核對 AI 字就送出：官方提醒生成圖文字可能錯字或唔係要求語言。
  • 上載後唔管理檔案：上載相入 OneDrive、專案計入儲存額度；唔想留可去 My projects／OneDrive 刪。
  • 以為一定永遠免費無限次：官方寫免費可用，想更頻密可能要訂閱；以帳戶顯示為準。

香港用戶留意

用瀏覽器開 designer.microsoft.com（或 Designer 手機 App），以個人 Microsoft 帳戶登入即可。官方 FAQ 寫明免費可用，想更頻密建立可訂閱；額度以帳戶畫面為準，本站唔報死數字。授權為 personal, non-commercial。上載相會入 OneDrive，計入 Microsoft 雲端儲存額度；唔想留檔可喺 My projects／OneDrive 刪。
