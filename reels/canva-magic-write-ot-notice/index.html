  • 點樣貼 OT 改期提示，再撳紫色圓形箭嘴（無障礙名稱「產生」）
  • 點樣撳「插入」，睇通告稿先抄去同事群

開始前準備

  • 瀏覽器開 canva.com，登入之後新建一個 Doc（文件）。魔法文案工具™ 喺文件入面，唔係整張海報。說明見 Use Magic Write
  • 先寫低改去邊一日、幾點到幾點。下面示範用「星河貿易」、星期三晚 7–9 點。真實公司名、同事名、電話、內部群先改走
  • 知道稿只係起稿。抄去群之前讀一次時間同語氣。未讀完唔好當通告已經出街

可抄提示

示範提示（虛構公司「星河貿易」，無真實同事名）

幫我寫一段畀香港同事 WhatsApp 群嘅短訊：聽朝原定加班改去星期三晚 7–9 點；語氣得體、簡潔、唔道歉過頭；結尾請大家回覆「收到」。公司名用「星河貿易」（虛構）。

你用 Teams 就將「WhatsApp 群」改成「Teams 群」。出嚟嘅短訊要自己讀：日子、時間、公司名。AI 加咗你冇寫嘅人名、電話、地址，先刪走。

3 步做法

2026-10-19 已登入繁中畫面：入口係 Doc 入面撳正斜線「/」（輸入框名稱「正斜線魔法輸入」），揀「魔法文案工具™」。唔係「快速動作」。送出掣畫面上係紫色圓形箭嘴，無障礙名稱「產生」，按鈕面冇寫「產生」。結果掣畫面上寫住「插入」，旁邊係「複製文字」。

  1. 開魔法文案：開 canva.com，登入，建一個 Doc（數碼）。喺文件入面撳鍵盤正斜線「/」，揀「魔法文案工具™」。面板標題就係「魔法文案工具™」。唔好揀「快速動作」，亦唔好當已經開咗海報工具。

    未貼提示之前，確認你冇打真實公司名、同事名、電話。空白頁中間寫住「開始鍵入文字或者問問 Canva 產生內容」。

  2. 撳產生：將上面嗰段星河貿易提示貼入去。送出掣畫面上係一顆紫色圓形箭嘴，冇寫「產生」兩個字。無障礙名稱係「產生」。未打字嗰陣箭嘴停用；貼好先至撳。示範公司同加班時段都係虛構。有真實公司、部門、上司名，撳之前先改走。

    稿未出齊就唔好當完成。魔法文案工具™ 用量視 Canva 方案而定。免費帳戶唔保證無限次，以你當日帳戶畫面為準。呢頁唔寫「免費無限」。

  3. 睇通告稿：結果出嚟之後，撳畫面上寫住「插入」嘅掣。旁邊嗰個係「複製文字」，唔係單獨一個「複製」。2026-10-19 插入之後，文件標題係「加班時間調整通知」，內文寫住：各位星河貿易的同事；原定於明早的加班時間已調整至星期三晚上 7 點至 9 點；麻煩大家看到訊息後回覆「收到」。對得上你自己嘅安排先改字，然後先抄去同事群。

    呢步係傳段通告，唔係叫人轉發呢則片。AI 可能會出錯，請檢查內容。插入之後都要刪走你冇寫嘅人名、電話、地址。

常見錯誤／注意事項

  • 話免登入：Canva 通常要登入。呢集唔寫免登入。
  • 揀「快速動作」：呢步係 Doc 入面撳正斜線「/」，再揀「魔法文案工具™」。唔係去撳一個寫住「快速動作」嘅掣。
  • 搵寫住「產生」兩個字嘅掣：畫面上係紫色圓形箭嘴。無障礙名稱先至係「產生」。
  • 揀錯工具：呢集用 Doc 入面「/」揀「魔法文案工具™」，寫一段短訊。唔係 Magic Design 出整張海報。
  • 當示範公司係真實：「星河貿易」同星期三晚 7–9 點係拍片用。無真實客戶、同事，唔好對號入座。
  • 貼真實公司資料：公司名、同事名、電話、內部群連結先刪走，再貼提示。
  • 見第一句就貼去群：等短訊出齊，讀完時間同語氣先抄。呢頁唔係叫你轉發呢則片。
  • 當用量無限：撳唔到「產生」就睇返帳戶額度，唔好當工具壞咗，亦唔好寫免費無限。
