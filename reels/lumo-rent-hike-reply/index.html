常見錯誤／注意事項

  • 當法律意見或者租務顧問：呢頁唔判斷加租合唔合法、通知期夠唔夠、業主有冇權加。覆訊只係得體咁問理據、議價空間同通知期。唔好當 Lumo 嘅句子係法律結論。

  • AI 亂加資料：電話、門牌、大廈名、租約編號、律師字眼，提示冇寫就先刪，再貼去 WhatsApp。
  • 見第一句就貼去 WhatsApp：等覆訊出齊，對一次稱呼、加幅、三個問題先抄。
  • 搵寫住 Start generating 嘅字：按鈕面無字，係一顆紫色圓箭。無障礙名稱先至係 Start generating。官方說明叫 Send。
  • 當用量無限：Guest 係有限用量。第42集畫面寫開帳戶先 increase limits。以你當日畫面為準。
  • 叫 Lumo 判加租：提示係叫佢寫一段問業主嘅覆訊。唔係叫佢話你應唔應該俾，亦唔係叫佢引法例。
