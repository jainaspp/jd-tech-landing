Lumo 3 步：Guest 私密整好同老細傾嘅講稿

香港人 AI 一招 · 第27集

2026-10-13 07:00

朝早要同老細面對面交代一件遲咗嘅事，臨出門先想有 3 點講稿：做到邊、卡喺邊、想佢拍板咩。第27集再用 Proton Lumo 嘅 Guest：唔使帳戶，打一句提示，等 3 點，撳 Copy。示範用虛構「陳小明／星河貿易」，唔貼真公司。

素材未齊：呢個 repo 冇 Ep.27 嘅 gen.py spec、cover 同逐步截圖，所以呢頁未嵌入影片，亦未寫 Lumo 實際回覆咗咩。下面撳掣名稱沿用 2026-10-11 喺同一 Guest 入口截到嘅畫面；講稿內容係按標題寫嘅虛構示範，唔係片入面嘅逐格回覆。介面改咗以當日網站為準。
Reel 一句講晒：Lumo｜同老細傾／3點講稿
唔係職場或法律意見：講稿只係開口起點。點樣交代、使唔使另外寫電郵留底，以你公司做法同合約為準。AI 可能出錯，亦可能加你冇講嘅數字。

你會學到

  • 點樣開 Lumo Guest，唔使帳戶打同老細傾嘅提示
  • 點樣叫佢分開 3 點：做到邊、卡喺邊、想上司決定咩
  • 點樣撳 Copy，對返事實先開口

開始前準備

  • 瀏覽器開 lumo.proton.me/guest（Guest 唔使帳戶）
  • 準備你可以公開嘅事實：做到邊、卡喺邊、你想老細決定嘅一個問題
  • 真公司名、真客名、金額、老細私人訊息，呢版示範唔會打落去

可抄提示

下面係按呢集標題寫嘅示範句。人名、公司同報表都係虛構。你自己用就換走，唔好連虛構名一齊講出去。

請用淺白粵語列 3 點講稿，畀我朝早同上司面對面講，每點兩句以內。虛構：本人陳小明，任職旺角一間叫「星河貿易」嘅公司文員。秋季客戶報表原定2026年10月13日交，估計10月15日先交到，原因係等客戶確認兩個數字，唔係我漏做。3 點分開：1) 做到邊 2) 卡喺邊 3) 想上司決定可唔可以10月15日先交。唔好捏造我冇講嘅金額、人名或者承諾。唔好寫成辭職信或者電郵。

3 步做法

  1. 開 Guest 打講稿提示：開 lumo.proton.me，用 Guest，唔使帳戶。將上面嗰段打入對話框。示範虛構「陳小明／星河貿易」，唔貼真公司、唔貼真客名。

    2026-10-11 喺同一 Guest 入口見到：空白對話、提示留喺輸入框、右下角紫色圓形箭咀，aria 名稱係「Start generating」。未撳之前，提示仍然留喺輸入框，方便你再睇一次有冇打多咗。

    Ghost Mode 可選。上一集示範保持關閉（Ghost OFF）。Guest 關窗即清；想留低對話先開帳戶。

  2. 撳紫箭咀：撳紫色箭咀（aria「Start generating」），等 3 點出齊。叫佢分開：做到邊、卡喺邊、想上司決定咩。

    出齊三點先再睇，唔好見到第一句就當完成。呢頁冇新截圖，所以唔寫 Lumo 實際回覆咗邊幾句。

    上一集畫面底寫「Lumo can make mistakes. Please double-check responses.」回覆區亦見到 “Conversation encrypted”。以你當日見到嘅字為準。

  3. 撳 Copy：回覆下面撳複製（Copy），抄走 3 點。對返你俾嘅事實：原定 2026年10月13日、估計 10月15日、原因係等客戶確認兩個數字。多咗出嚟嘅金額、人名、或者「我保證星期五一定交」呢類承諾，刪走先開口。

    呢 3 點係面對面講，唔係電郵，亦唔係辭職信。如果公司要書面留底，自己另外寫，唔好將 AI 稿直接轉寄。

    示範用虛構「陳小明／星河貿易」，唔貼真公司。呢份講稿唔係職場或法律意見。

常見錯誤／注意事項

  • 打真公司同真客名：示範用虛構「陳小明／星河貿易」，唔貼真公司。客名、金額、老細私人訊息留返你自己講，唔好打落去。
  • 照稿讀：AI 可能加你冇講嘅日期或者承諾。對返做到邊、卡喺邊、你想佢決定嘅問題，先開口。
  • 當職場意見：遲交點樣交代、使唔使寫電郵，唔係 Lumo 可以話實。跟你公司做法。
  • 以為 Guest 會幫你存檔：Guest 關窗即清。Ghost Mode 可選，上一集示範保持關閉。想留低先登入開帳戶。
  • 當畫面永遠一樣：紫色箭咀、複製圖示以當日網站為準。呢頁冇 Ep.27 嘅新截圖。
