Copilot 3 步：長文網頁變重點

長文網頁 3 步變重點？！

最後核實：2026-09-25

跟 Reel 用 Microsoft Edge 內建 Copilot 將長網頁變成 3 點重點：開 Edge 登入、問總結、複製重點。附私隱開關、可抄 Prompt 同官方說明。

Reel 一句講晒：長文網頁 3 步變重點？！

你會學到

  • 喺 Edge 開 Copilot 摘要而家睇緊嘅網頁
  • 點樣問先拎到「只根據呢頁」嘅重點
  • Copilot 會讀取咩瀏覽資料、點樣關

開始前準備

  • Microsoft Edge（電腦或手機）
  • Microsoft 帳戶
  • 一篇要讀嘅長網頁或 PDF

3 步做法

  1. 開 Edge 登入：開 Microsoft Edge，撳工具列嘅 Copilot，用 Microsoft 帳戶登入；唔用 Edge 可以去 copilot.microsoft.com。

    官方講 Copilot in Edge 係瀏覽器內建嘅 AI 助手，可以摘要網頁、影片同 PDF，手機版 Edge 都有。

    用 copilot.microsoft.com 嘅話，就要自己貼網址或者文字入去。

  2. 問「用 3 點總結」：開住要讀嘅網頁，喺 Copilot 問：「用 3 點總結呢頁重點」。

    官方寫明，當你嘅問題係關於頁面內容，Edge 可能會用而家個頁、頁面標題、開住嘅分頁同瀏覽紀錄去答。所以問之前，關咗唔相關嘅分頁，答案會更集中。

    官方亦有一撳即出嘅頁面摘要；自己打問題嘅好處係可以限定格式，例如「3 點、每點 20 字內」。

  3. 複製重點：將重點複製去 WhatsApp、Notes 或 Notion；重要嘅句子返原文對一次。

    摘要係幫你決定「要唔要細睇」，唔係代替原文。數字、日期、條款一定返原文核對。

    對話清咗就冇，有用嘅重點即刻複製存低。

可抄 Prompt

只根據呢頁嘅摘要

請摘要呢一頁，用繁體中文：
1. 一句話結論
2. 5 個重點（每點 20 字內）
3. 1 個我應該自己再查嘅地方
只根據目前頁面，唔好用頁外知識補完。

變成行動清單

將呢頁變成行動清單表格：要做咩｜邊類人負責｜有冇限期（冇就寫「未提及」）。

常見錯誤／注意事項

  • 答案講埋頁面冇嘅嘢：可能讀錯分頁，或者讀取網頁脈絡嘅開關未開。
  • 開住敏感分頁問 Copilot：官方提醒唔好分享唔想被用作瀏覽脈絡嘅敏感資料；可以關分頁、清瀏覽紀錄。
  • 公司電腦功能被鎖：跟公司政策，唔好為方便將內部文件貼去個人 AI 帳戶。
  • 摘要當法律或政策意見：只係閱讀輔助。

官方開關位置：Edge 工具列「⋯」→ Copilot and AI → Allow Copilot to read context clues on the web。

香港用戶留意

Microsoft 官方地區說明寫明 Copilot 唔提供嘅例外係中國內地（不包括香港），即係香港唔喺例外名單。個別新功能可能逐步推出，以你帳戶畫面為準。

官方說明

  • Getting started with Copilot in Microsoft Edge（Microsoft Support）
    官方講 Edge 內 Copilot 點樣摘要網頁／PDF，同埋讀取網頁脈絡嘅私隱開關
  • Supported regions and languages in Microsoft Copilot（Microsoft Support）
    官方地區說明：中國除外名單註明「不包括香港」
