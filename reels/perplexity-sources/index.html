Perplexity 3 步：查料要有來源

唔好再叫聊天機械人估新聞。查料同傾偈，係兩件事。

最後核實：2026-09-25

跟 Reel 用 Perplexity 查新聞同數據：問清楚、睇編號來源、撳開核對。附可抄 Prompt、來源標籤點睇同官方說明。

Reel 一句講晒：唔好再叫聊天機械人估新聞。查料同傾偈，係兩件事。

你會學到

  • 點解查新聞同數據要用有來源嘅答案
  • 點樣問 Perplexity 先拎到有用嘅來源
  • 撳開來源之後要核對咩

開始前準備

  • 瀏覽器打開 perplexity.ai（或 App）
  • 一條你想查嘅問題，最好寫埋地區同時間範圍

3 步做法

  1. 問清楚：開 perplexity.ai，用完整問題問：寫明地區、時間範圍，同埋你要官方或一手來源。

    冇上網搜尋嘅聊天回答，可能靠訓練資料「估」，未必係最新。查新聞、數據、政策呢類會變嘅嘢，就要用會搜尋、會列來源嘅工具。

    例子：「香港 2026 年公共圖書館電子書點樣登記？請附官方來源。」

  2. 睇編號來源：答案出嚟之後，睇每句旁邊嘅編號引用同來源列表。

    官方講每個答案都有編號引用，連去原本嘅來源，等你自己核對。

    有啲來源有盾牌標籤（Government、Academic、Trusted）。官方寫明標籤係按成個網站評，唔係逐頁保證，所以都要睇內容。

  3. 撳開核對：最少撳開兩條最關鍵嘅來源，確認原文真係咁講、日期夠唔夠新。

    喺原文用 Ctrl+F 搵答案入面嘅數字或關鍵句；搵唔到，就當嗰句未證實。

    引用喺功課或報告，要引原本網頁，唔好只寫「根據 AI」。

可抄 Prompt

要有來源嘅問法

問題：【你嘅問題】
地區：香港
請用繁體中文回答，並：
1. 先講結論
2. 列步驟或要點
3. 每個要點都要有可以撳開嘅來源
4. 資料可能過時嘅地方請寫明

核對一句講法

我見到呢句講法：【貼上】
請幫我核對有冇可靠來源支持；有嘅話俾連結同原文關鍵句；冇嘅話直接講證據不足。

常見錯誤／注意事項

  • 唔撳來源就信：引用存在唔等於內容支持嗰句。
  • 見到來源標籤就當保證：標籤係評網站，唔係評每一頁。
  • 問題太闊：「講下 AI」冇用，收窄地區、時間同你要嘅格式。
  • 報稅、簽證、醫療只信 AI：最後一步一定返對應部門嘅官方頁。

官方說明

  • How does Perplexity work?（Perplexity Help Center）

  • Understanding source labels（Perplexity Help Center）
