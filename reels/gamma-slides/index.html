Gamma 簡報 3 步：大綱變 slides

整簡報又拖到通宵？免費 3 步出齊 slides。

最後核實：2026-09-25

跟 Reel 用 Gamma 將大綱變成可改嘅簡報：貼大綱、Generate、改字再匯出 PPTX／PDF。附可抄 Prompt、credits 注意事項同官方說明連結。

Reel 一句講晒：整簡報又拖到通宵？免費 3 步出齊 slides。

你會學到

  • 點樣用 Paste 模式，將你自己嘅大綱變成一疊簡報卡
  • 生成前喺預覽刪頁，慳返 AI credits
  • 逐頁改字、最後先換主題，再匯出 PowerPoint（PPTX）或 PDF

開始前準備

  • Gamma 帳戶（電腦瀏覽器最順手）
  • 一段 5–8 點嘅大綱，寫埋對象同時長
  • Gamma 官方寫明：新免費用戶開戶有 400 credits；AI 功能按頁、按圖扣 credits；免費計劃用完唔會自動補充

3 步做法

  1. 貼大綱：登入 gamma.app，喺 Dashboard 撳 Create New AI，揀 Paste，將你嘅大綱貼入去。

    Gamma 有三個起步方法：Generate（只打一個主題）、Paste（貼你已有嘅大綱或筆記）、Import（匯入現有檔案）。Reel 用嘅係「貼大綱」，因為內容由你話事，AI 只係幫你排版，唔會自己作一堆你講唔出口嘅嘢。

    大綱每點一句就夠，寫埋對象同時長，例如「對象：同學；8 分鐘；繁體中文；約 8 頁」。

  2. Generate：揀 Presentation，睇一次預覽大綱，冇問題先撳 Generate。

    生成前可以揀語言、每頁字數、風格同圖片設定。預覽大綱嗰步好重要：頁數太多就喺呢度刪。

    原因好實際：官方寫明用 AI 生成簡報係按頁同按圖計 credits，頁數愈多、圖愈多，用得愈多。

  3. 改字再匯出：逐頁改字、刪走冇來源嘅數字，最後先換 Theme，再經 Share → Export 匯出 PDF 或 PowerPoint（PPTX）。

    自己打字改文字係普通編輯；叫 AI 重做一頁、加頁、試新版面先屬 AI 功能，會用 credits。所以唔滿意一兩句，手改最慳。

    官方匯出格式有 PDF、PNG 同 PowerPoint（PPTX），PPTX 入面嘅表格仲可以再改。匯出結果會跟 Present 模式一樣，所以匯出前用 Present 睇一次。

可抄 Prompt

貼入 Paste 模式嘅大綱模板

主題：【簡報題目】
對象：【老闆／同學／客人】
時長：【例如 5 分鐘】
大綱：
【貼上 5–8 點】
請做成簡報結構，每頁一個重點，繁體中文，語氣【專業／輕鬆】，唔好捏造統計數字。

某一頁太長時用

呢一頁太長：請改成「標題＋最多 3 個要點」，保留原意，用繁體中文。
原文：
【貼上該頁文字】

常見錯誤／注意事項

  • 一開頭就 Generate 一個好闊嘅題目：內容會飄、頁數多，credits 亦用得快。改用 Paste 貼自己大綱。
  • 唔滿意就成份 regenerate：每次 AI 動作都會扣 credits。單頁微調，或者直接手改字。
  • 每頁寫到好似文章：簡報每頁一個重點，細節留返口講。
  • 照用 AI 加嘅統計數字：冇來源就刪，或者換成你自己查到、有出處嘅數字。
  • 唔好上載機密資料：未公開財務、客人名單唔好放入個人帳戶再隨意分享連結。
