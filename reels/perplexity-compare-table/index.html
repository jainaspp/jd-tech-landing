Perplexity 3 步：比較 A 同 B 出有來源表

比較 A 同 B，3步出一張有來源嘅表

最後核實：2026-09-27

跟 Reel 用 Perplexity 比較兩個選項：寫清地區年份、叫佢做成「項目｜A｜B｜來源」表、撳開來源核對。附可抄 Prompt 同官方說明。

Reel 一句講晒：比較 A 同 B，3步出一張有來源嘅表

你會學到

  • 點解比較唔好淨係問「邊個好啲」
  • 點樣叫 Perplexity 逐行附來源做成表
  • 撳開來源之後要核對咩

開始前準備

  • 瀏覽器打開 perplexity.ai（或 App）
  • 兩個你想比較嘅選項（例如兩隻電話月費計劃、兩間補習社）
  • 最好寫埋地區同時間範圍（例如香港、今年）

3 步做法

  1. 開 Perplexity、寫清範圍：開 perplexity.ai，問題寫清地區同年份（例如：香港、今年、只要官方資料）。

    範圍愈清楚，來源愈有用。淨係問「邊個好」會令答案變空泛推薦，難核對。

    例子：「香港、今年，比較【計劃 A】同【計劃 B】；只要官方或一手資料。」

  2. 叫佢做成有來源嘅表：打：「比較【A】同【B】，做成表：項目｜A｜B｜來源；揟唔到就寫『未找到』，唔好估」。

    官方講每個答案附編號引用，方便你自己核對。逼佢用表同「未找到」欄，漏咚一眼睇到。

    唔好淨係要結論；要逐行有來源，之後先容易撳開核對。

  3. 撳開最關鍵來源核對：撳開最關鍵嘅兩條來源，睇下係哋官網／一手資料、有冇過時。

    有啲來源有盾牌標籤（Government、Academic、Trusted）。官方寫明標籤係按成個網站評，唔係逐頁保證，所以都要睇嗰頁真係有冇寫。

    嗰原文用 Ctrl+F 揟表入面嘅數字或關鍵句；揟唔到，就當嗰格未證實。

可抄 Prompt

比較 A 同 B（有來源表）

比較【A】同【B】。
地區：香港
時間：今年（或寫明年份）
只要官方或一手資料。

請用繁體中文做成表：
項目｜A｜B｜來源連結或出處
揟唔到就寫「未找到」，唔好估。
最後用 3 點講兩邊主要分別，每點都要可對返表入面嘅來源。

核對表入面一行

呢行講法：【貼上項目同數字】
請幫我核對有冇可靠來源支持；有嘅話俾連結同原文關鍵句；冇嘅話直接講證據不足。

常見錯誤／注意事項

  • 淨係問「邊個好啲」：冇表、冇來源，好難核對。要叫佢逐行附來源。
  • 見到來源標籤就當保證：標籤係評網站，唔係評每一頁。
  • 唔撳開來源：引用存在唔等於嗰頁真係咁講。
  • 報稅、簽證、醫療只信 AI：最後一步一定返對應部門或機構嘅官方頁。
