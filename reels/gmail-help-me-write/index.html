Gmail Help me write 3 步：粗糙要點寫成電郵

粗糙要點寫成電郵

最後核實：2026-10-05

跟 Reel 用 Gmail Help me write：Compose 開新信、正文打低粗糙要點 → 揀 Formalize 叫 Gemini 寫成正式語氣 → 睇清楚先接受（手機 App 撳 Replace）。附合資格方案、個人帳戶只限美國、電腦版同手機版介面分別。

Reel 一句講晒：粗糙要點寫成電郵

你會學到

  • 點喺 Gmail 寫信畫面開 Help me write（電腦版 prompt bar／手機 App 右上角）
  • 點用 Formalize 將零散要點變成正式電郵，再 Shorten／Friendly 調整
  • 點解要合資格 Workspace／Google AI 方案，同寄出前要自己核對內容

開始前準備

  • 電腦瀏覽器開 Gmail，或者手機 Gmail App（Android／iPhone）
  • 合資格 Google Workspace 或 Google AI 方案；官方寫明個人帳戶只限美國
  • 幾行粗糙要點（例如跟進項目、負責人、限期）；敏感資料唔好交畀 AI

3 步做法

  1. 開 Compose 撳幫我寫：開 Gmail 撳 Compose 開新信，將粗糙要點打喺正文，跟住搵 Help me write（幫我寫）。

    官方 Gmail Help（電腦版）：At the top left, click Compose → 喺正文打你嘅訊息（或者留空）→ 底部 prompt bar；搵唔到 prompt bar 就撳 Help me write。回覆或者開舊草稿都用得。

    手機 Gmail App（Android／iPhone）：右下角撳 Compose，寫好草稿後喺右上角撳 Help me write。

    官方寫明要合資格 Google Workspace 或 Google AI 方案；個人 Google 帳戶只限美國。唔聲稱香港一定有——以你自己寫信畫面有冇 Help me write 為準。

  2. 揀 Formalize：揀 Formalize，叫 Gemini 將要點寫成正式電郵語氣；亦可以再揀 Shorten 等選項或者自己打指示。

    官方用途例子就係「turn a rough outline into a formal email」——將粗糙大綱變正式電郵。

    電腦版 prompt bar 官方列出 Formalize、Friendly、Shorten，亦可以打新指示，例如「Make it more professional」「Mention the Friday deadline」。

    手機 App 選單官方列出 Polish、Formalize、Elaborate、Shorten。想由空白開始，就喺 prompt 打一句描述（例如收件人、主題、語氣），撳 Create。

  3. 睇清楚先接受：睇完預覽，滿意先接受（手機 App 撳 Replace 取代原本草稿）；唔啱就再出一版或者改指示。

    手機 App 官方：To accept the new draft, tap Replace；想再出一版撳 Recreate（官方提醒出咗新版就返唔到上一版）。

    電腦版官方：喺 prompt bar 右邊撳 Undo／Redo 切換唔同版本。

    官方提醒 Gemini 建議可能唔準；Help me write 亦會參考你其他電郵同 Drive 檔案嚟個人化——寄出前自己核對人名、日期同事實（可撳 Sources 睇佢參考咗咩）。

可抄 Prompt

要點變正式信（自己打指示）

Make it more professional.

加入限期（官方例子）

Mention the Friday deadline.

常見錯誤／注意事項

  • 冇 Help me write 就以為壞咗：官方寫明要合資格 Workspace／Google AI 方案，個人帳戶只限美國；以你自己寫信畫面為準。
  • 唔睇就寄：官方提醒 AI 建議可能唔準；人名、日期、金額、承諾一定要自己核。
  • 以為電腦版同手機版掣一樣：電腦版係 prompt bar（Formalize／Friendly／Shorten＋Undo／Redo）；手機 App 先有 Polish／Elaborate／Recreate／Replace。
  • 敏感資料交畀 Gemini：密碼、客戶私隱、未公開商業資料唔好打入要點；留意佢會參考你其他電郵同 Drive 檔案。

香港用戶留意

官方寫明個人 Google 帳戶用 Help me write 只限美國；合資格 Google Workspace 或 Google AI 方案就喺支援語言下全球可用。唔聲稱香港帳戶一定有；請喺自己 Gmail 寫信畫面睇下有冇 Help me write／prompt bar。
