MicroLLM 3 步：瀏覽器本地細模型傾偈

香港人 AI 一招 · 第30集

2026-10-14 12:00

想試 AI，又唔想對話上雲、唔想註冊。第30集用 MicroLLM lab：喺瀏覽器揀 SmolLM2 135M Instruct，撳 Load，打一句示範 Haiku，撳 Generate，回覆留喺自己部機。工具名就係 MicroLLM lab。

Reel 一句講晒：MicroLLM｜本地傾偈／唔上雲
唔係正式答案：近日瀏覽器本地細模型實驗。無 WebGPU 會 fallback WASM／CPU。細模型易幻覺，唔好當正式答案。免費免註冊；權重存 IndexedDB。示範提示係一首 Haiku，唔係事實查核。

你會學到

  • 點樣開 MicroLLM lab，揀 SmolLM2 135M Instruct 撳 Load
  • 點樣等畫面寫 Loaded，打示範提示再撳 Generate
  • 點樣睇瀏覽器內本地回覆，同埋無 WebGPU 時點樣 fallback

開始前準備

  • 瀏覽器開 stateofutopia.com/experiments/microllmlab。唔使註冊，亦唔使 API key
  • 預留時間下載模型。SmolLM2 135M Instruct 嘅權重會存入呢個瀏覽器嘅 IndexedDB，第一次會慢過之後
  • 用一句短提示試。示範用英文 Haiku。135M 主要係英文細模型，廣東話長問答唔好期望佢答得穩

可抄提示

下面係打入 Chat 之後撳 Generate 嘅示範句。Gigazine 2026-10-13 實測用過另一句改寫電郵；本集跟片，用一首 Haiku。回覆可能唔成俳句、可能中途停，唔好當成品。

Write a haiku about a quiet evening. Three short lines only. This is a demo of a tiny local model.

3 步做法

  1. 撳 Load：開 MicroLLM lab，喺模型清單揀 SmolLM2 135M Instruct，撳 Load。等呢張卡寫 Loaded。示範就用呢個 135M，唔使一次過 Load 晒七個模型。

    官方頁寫：撳 Load 之後，權重會快取喺瀏覽器私人 IndexedDB。頁面亦寫到可以 Load all models；本集只載一個就夠傾偈。

    未見到 Loaded 就唔好打提示。下載中斷就再撳一次 Load。

  2. 撳 Generate：模型 Loaded 之後，捲去 Chat，將上面嗰句 Haiku 提示打入去，撳 Generate。

    Gigazine 2026-10-13 嘅實測同樣係喺 Chat 打提示，再撳 Generate。佢哋見到預設輸出上限可以令句子中途停。見到回覆停喺半句，就當細模型限制，唔好當佢講完。

    提示留喺自己部機。開發者說明用戶輸入唔會送去外部 AI 服務。

  3. 睇回覆：睇瀏覽器入面嘅本地回覆。有 WebGPU 會用裝置 GPU；無 WebGPU 會 fallback WASM，再落到 CPU 上嘅 JavaScript。WebGPU 可選，唔係先決條件。

    頁面 Runtime 可以見到 backend。如果寫 WASM 或者 JS，代表冇行到 GPU，仍然係本地計算，只係慢啲。

    細模型質素有限，容易幻覺。Haiku 示範唔好當文學成品，亦唔好用呢個 135M 答事實、醫療或者錢銀問題。

常見錯誤／注意事項

  • 當雲端聊天機械人：SmolLM2 135M 係細模型。事實、數字、廣東話長文都可能錯。唔好當正式答案。
  • 無 WebGPU 就放棄：官方頁寫 Prefer WebGPU，行唔到會 fallback WASM，再落到 JS。CPU 都傾到偈，只係慢。
  • 以為要註冊：實驗室頁寫 zero accounts。唔使帳戶，亦唔使 API key。權重存在呢個瀏覽器嘅 IndexedDB。
  • 一次 Load 晒先算完成：清單有幾個模型。本集示範只 Load SmolLM2 135M Instruct。Load all 會下載更多，唔係傾一句偈嘅必要步驟。
  • 回覆停半句就當壞咗：Gigazine 當日見到輸出 token 上限會截斷句子。可以再試短提示，仍然唔好當成品。

近日瀏覽器本地細模型實驗。無 WebGPU 會 fallback WASM／CPU。細模型易幻覺，唔好當正式答案。免費免註冊；權重存 IndexedDB。

香港用戶留意

用瀏覽器開上面條連結就得，示範冇註冊、冇裝 App。介面掣名係英文：Load、Loaded、Generate。SmolLM2 135M Instruct 主要處理英文，所以示範提示用英文 Haiku。手機都可以試，第一次下載會食數據同儲存。
