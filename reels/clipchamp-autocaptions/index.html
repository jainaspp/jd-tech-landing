Clipchamp 3 步：口播片自動出字幕

口播片自動出字幕

最後核實：2026-09-30

跟 Reel 用 Microsoft Clipchamp autocaptions 幫有人聲口播片自動出字幕：開專案拖入片、開 autocaptions、揀語言轉寫再 Export。附 .SRT 下載同 Azure／ASR 私隱說明。

Reel 一句講晒：口播片自動出字幕

你會學到

  • 點樣喺 Clipchamp（Web 或 Windows App）開專案，將有人聲片拖入時間軸
  • 點用 preview 上 captions icon 或者 property panel 嘅 captions tab 開 autocaptions
  • 點揀語言、Transcribe、改錯字、Export，同埋有需要時下載 .SRT

開始前準備

  • Microsoft 帳戶；瀏覽器開 app.clipchamp.com，或者 Windows 裝好 Clipchamp App
  • 一段有人聲嘅口播／會議片（官方寫明 autocaptions 只適用有人聲嘅片／音訊）
  • 有私隱或敏感內容嘅片，先衡量要唔要開 autocaptions（會經 Azure／Microsoft ASR 處理音訊）

3 步做法

  1. 開專案拖入有人聲片：開 Clipchamp（app.clipchamp.com 或 Windows Clipchamp App），開專案，將有人聲嘅片拖入時間軸（官方寫明 autocaptions 只適用有人聲嘅片／音訊）

    官方 Support：由 My media 匯入有旁白嘅片或音訊，再拖入時間軸開始編輯。

    官方 Blog：撳 import media 由電腦或 OneDrive 匯入，再拖去時間軸。

    產品頁：可用瀏覽器 in-browser editor，或 Windows 11 Start menu／Microsoft Store 嘅 Clipchamp App。

  2. 開 Autocaptions：撳 preview 上 captions icon，或者 property panel 嘅 captions tab，開 autocaptions

    官方 Support／Blog：撳 video preview 嘅 captions icon，或者 property panel 嘅 captions tab，開啟 autocaptions。

    官方註：autocaptions 只相容包含人聲（voice）嘅片或音訊；冇人聲就唔會出字幕。

    開咗之後會有彈窗，跟提示揀轉寫語言，同可選過濾冒犯用語，再撳 Transcribe（官方寫 Transcribe media）。

  3. 轉寫、改錯、Export：揀語言 → Transcribe → 改錯字 → Export；需要可以下載 .SRT

    官方：字幕會出現喺 preview；可編輯 transcript 同時間戳喺 captions tab；雙擊改錯字或刪字。

    官方：可撳 download captions 下載 .SRT 檔。

    官方：預覽滿意後 Export，揀你要嘅解像度。

    官方 FAQ：開 autocaptions 時會用 Azure Cognitive Services／Microsoft Automatic Speech Recognition（ASR）處理音訊，無人手接觸音訊；Caption 資料存喺你嘅 Clipchamp 專案，只有你可存取。有私隱或敏感內容嘅片，自己衡量先決定開唔開。

    官方 Blog／subtitle-generator FAQ：autocaptions 對所有用戶免費（包括免費用戶同付費訂閱）。每片只支援一種轉寫語言。

常見錯誤／注意事項

  • 片冇人聲就開 autocaptions：官方寫明只適用有人聲嘅片／音訊；冇 voice 就唔會出字幕。
  • 唔改錯字就出街：官方允許喺 transcript 雙擊改字；店名、價錢、專有名詞要人手核。
  • 敏感內容唔衡量就開：官方寫明會用 Azure／Microsoft ASR 處理音訊；唔想處理就唔好開 autocaptions。
  • 以為一定要付費先有：官方 FAQ 寫明 autocaptions 對所有用戶免費；實際介面以你帳戶畫面為準。

香港用戶留意

可用瀏覽器（app.clipchamp.com／clipchamp.com）或 Windows Clipchamp App。Autocaptions 官方 FAQ 寫明對所有用戶免費（含免費用戶）。官方寫明只適用有人聲嘅片／音訊；開 feature 時會用 Azure Cognitive Services／Microsoft ASR 處理音訊。介面掣名以個人版 Support 為準（Work／school 版可能寫法唔同）。語言種數官網唔一致（主頁 over 80／subtitle-generator over 100）——本站唔報具體種數。

官方說明

  • How to use autocaptions in Clipchamp（Microsoft Support）
    2026-09-30 核實：只適用有人聲片／音訊；Import→拖入時間軸→captions icon／captions tab→揀語言→Transcribe→改錯→Export；可下載 .SRT；處理用 Azure Cognitive Services；Microsoft ASR 無人手介入；Caption 資料存喺專案；唔開 feature 就唔處理
  • How to use autocaptions in Clipchamp（Clipchamp Blog）
    2026-09-30 核實：FAQ「Autocaptions are free for all users, including free users and paid subscribers」；步驟同 Support 一致；可下載 .SRT；每片只支援一種轉寫語言
  • Auto subtitle generator（Clipchamp）
    2026-09-30 核實：FAQ「The autocaptions feature is free for all Clipchamp users.」；可下載 .SRT；speech recognition 無人手介入
  • Microsoft Clipchamp 產品頁
    2026-09-30 核實：in-browser 同 Windows app；AI subtitle generator；app.clipchamp.com 會轉去 consumer 編輯器
