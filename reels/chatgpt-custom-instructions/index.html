ChatGPT 自訂指令 3 步：規矩講一次之後自動跟

規矩講一次之後自動跟

最後核實：2026-09-29

跟 Reel 用 ChatGPT Custom Instructions 設一次做事規矩：開 Personalization、寫角色／答法／紅線、開新對話試改電郵。附字數上限同香港地區說明。

Reel 一句講晒：規矩講一次之後自動跟

你會學到

  • 點樣喺 chatgpt.com 打開 Enable customization 同填 Custom Instructions
  • 點寫三句穩定規矩：你做咩、想點答、禁止捏造咩
  • Free／Go 最多 1,500 字符；Plus 等計劃可到 5,000（官方 Help）

開始前準備

  • 一個 ChatGPT 帳戶（官方寫明所有計劃都有 Custom Instructions，包括 Free）
  • 瀏覽器打開 chatgpt.com，或者手機 App（iOS／Android）
  • 諗好三句：你做咩工作、想點答（語言／長度／格式）、紅線（唔好捏造日期價錢）

3 步做法

  1. 打開自訂設定：用瀏覽器開 chatgpt.com，入 Settings → Personalization（手機 App：Settings → Customize ChatGPT），確認 Enable customization 已打開

    官方 Help：Custom Instructions 喺所有計劃都有，支援 Web、Desktop、iOS、Android。

    官方步驟（網頁／桌面）：Settings → Personalization，打開 Enable customization，再喺 Custom Instructions 欄填寫。

    官方步驟（iOS／Android）：Settings → Customize ChatGPT，打開 Enable customization，再填 Custom Instructions。

    實際揪名以你畫面為準。

  2. 寫你想佢記住嘅規矩：喺 Custom Instructions 寫你想佢記住嘅規矩，例如：你做咩工作、想點答（書面中文／列點／長度）、紅線（唔好捏造日期價錢）。Free／Go 帳戶最多 1,500 字符；Plus 等計劃可到 5,000（以官網為準）

    官方 FAQ：Free 同 Go 用戶最多可儲存 1,500 characters；Plus、Pro、Enterprise、Business、Education 用戶最多 5,000 characters。

    夠用結構：身份同場景＋輸出習慣＋紅線。唔使寫人生傳記。

    公司機密、客人電話、密碼唔好寫入自訂指令——呢句係使用提醒，唔係官方句子。

  3. 開新對話試一次：儲存後開新對話試改一封內部電郵或一段報告；唔啱就返去改指令。官方寫明更新會即時套用所有對話

    官方：Your custom instructions are applied immediately to all chats；Updates to custom instructions settings are applied immediately across all chats (including existing conversations)。

    同一篇官方 FAQ 亦寫：更新後，舊對話紀錄入面可能仍見到舊指令版本；要清走舊紀錄可刪除該啲對話。實務上開新對話試一次最穩陣。

    對外承諾同數字一定自己終審——呢句係使用提醒。

可抄 Prompt

可抄自訂指令骨架（書面中文）

我係香港上班族，日常處理內部電郵同簡短報告。
請用書面中文回覆，先結論後細節，需要時用列點；句子要短。
唔好捏造日期、價錢、法例或我冇提供嘅資料；唔好加我冇講過嘅承諾。

常見錯誤／注意事項

  • 指令寫到好長又空：改做「我做咩＋想點答＋禁止咩」三句就夠。
  • 把機密寫入指令：客人電話、密碼、未公開商業條款唔好放；用「客人 A」代替。
  • 改完指令唔開新對話試：官方寫設定會即時套用；實務上開新 chat 對比最清楚。
  • 當自訂指令係一次性 prompt：指令應該係穩定偏好；單一任務細節仍要喺該則對話講清楚。

香港用戶留意

OpenAI 官方支援地區名單截至最後核實日未列出 Hong Kong。本站唔教任何規避方法；香港用戶可以用 Gemini 做同一件事（Gemini 網頁版官方地區名單包括 Hong Kong）。
