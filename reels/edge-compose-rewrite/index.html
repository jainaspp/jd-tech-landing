Edge Compose 3 步：網頁即改寫

網頁即改寫

最後核實：2026-10-03

跟 Reel 用 Microsoft Edge Inline Compose：喺電郵／表單可編輯欄打草稿 → 反白 → 浮現 Copilot 或右鍵 Rewrite with Copilot → 調 tone／format／length → 核對先再送。附官方 Edge 124+、可關閉寫作輔助同私隱說明。

Reel 一句講晒：網頁即改寫

你會學到

  • 喺 Edge 可編輯欄反白草稿，叫出 Rewrite with Copilot／Draft with Copilot
  • 點樣調 tone／format／length 再揀一版貼返欄入面
  • 點解要自己核對事實同語氣，同點喺設定關閉網頁寫作輔助

開始前準備

  • 電腦裝咗較新版 Microsoft Edge（官方由版本 124 起有 Inline Compose）
  • 一個有可編輯輸入欄嘅網頁（電郵網頁版、表單、客服回覆欄等）
  • 敏感內容（密碼、客戶私隱、未公開商業資料）唔好交畀 AI 改寫

3 步做法

  1. 開 Edge 輸入框：用 Microsoft Edge，喺電郵／表單等可編輯欄打好草稿。反白要改嗰段字。

    官方 Edge Blog：由版本 124 起，AI Compose 可喺文件可編輯文字區 inline 使用。

    Privacy Whitepaper：喺任何輸入文字欄 highlight 文字（官方寫 longer than five words）再叫 Rewrite。

    例子：把「遲咗到，sorry」改成較正式但短嘅到勤通知。唔同網站輸入欄未必都出現 Compose。

  2. Rewrite with Copilot：撳浮現嘅 Copilot 圖示，或者右鍵揀 Rewrite with Copilot（空白欄可用 Draft with Copilot）。調 tone／format／length，再揀一版貼返欄入面。

    官方 Inline Compose FAQ：浮現掣或右鍵 Rewrite with Copilot／Draft with Copilot；可調 tone、length、format。

    Edge Blog：Select a section of text → click the Copilot icon → iterate AI proposals；change tone, format, or length。

  3. 核對先再送：AI 建議要自己核對事實同語氣；官方提醒系統偶有誤導內容。唔想用可去 Edge 設定關閉網頁寫作輔助。企業機可能由管理員政策控制。

    官方 FAQ：AI systems might occasionally show harmful or misleading content——唔好盲信。

    關閉：Inline Compose FAQ 寫 Collaborate with Copilot as you write on the web；Privacy Whitepaper 寫 Languages → Writing assistance 入面可關 Draft with Microsoft 365 Copilot as you write on the web（介面字眼可能隨版本變，以你 Edge 設定為準）。

    私隱：文字喺你撳 Rewrite／Generate 之後先送去 Microsoft；詳見 learn.microsoft.com Edge Privacy Whitepaper Compose 節。企業可用 ComposeInlineEnabled 等政策。

常見錯誤／注意事項

  • 唔反白就撳：要先喺可編輯欄反白（官方提示長過約五個字），先有浮現掣／右鍵 Rewrite。
  • 盲信 AI 建議：官方提醒偶有誤導內容；事實、語氣、收件人稱呼要自己核。
  • 敏感內容交畀 AI：撳 Rewrite 後文字會送去 Microsoft；密碼、客戶私隱唔好用。
  • 以為每個網站都有：官方寫部分網頁或欄位未必有 Compose；企業機可能被政策關掉。

香港用戶留意

需要 Microsoft Edge（官方由版本 124 起有 Inline Compose）。喺電郵／表單等可編輯欄反白文字後用浮現 Copilot 圖示或右鍵 Rewrite with Copilot。唔同網站輸入欄未必都出現。敏感內容唔好交畀 AI 改寫；企業機可能由管理員政策控制。私隱見 Microsoft Edge Privacy Whitepaper（Compose 節）。
