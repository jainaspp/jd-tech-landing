常見錯誤／注意事項

  • 話免登入：Canva 通常要登入。呢集唔寫免登入。
  • 揀「快速動作」：呢步係 Doc 入面撳正斜線「/」，再揀「魔法文案工具™」。唔係去撳一個寫住「快速動作」嘅掣。
  • 搵寫住「產生」兩個字嘅掣：畫面上係紫色圓形箭嘴。無障礙名稱先至係「產生」。
  • 揀錯工具：呢集用 Doc 入面「/」揀「魔法文案工具™」，寫一段徵人帖。唔係 Magic Design 出整張海報。
  • 當示範茶餐廳係真實：洗碗、幫檯、週末兼職、旺角、星期六日 11:00–15:00、時薪 HK$70，都係拍片用。無真實店名、無真實電話。
  • 當稿係勞工處招聘或者僱傭合約：時薪、工時、假期、保險跟你自己茶餐廳同當日做法。AI 加咗嘅人工規則先刪走。呢頁唔判斷法例。示範時薪 HK$70 唔係法定時薪。
  • 見第一句就貼去 IG：等徵人帖出齊，對一次日子同職責先貼。
  • 貼真實個人資料：電話、地址、時薪、店名先刪走，再貼提示。
  • 當用量無限：撳唔到「產生」就睇返帳戶額度，唔好當工具壞咗，亦唔好寫免費無限。
  • 當呢頁係叫你轉發片：可以貼嘅係你讀過嘅徵人帖。呢頁唔係叫你轉發呢則片。
