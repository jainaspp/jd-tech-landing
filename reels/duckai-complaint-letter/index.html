Duck.ai 3 步：免登入出正式投訴信

2026-10-19 07:00

網購壞機，客服拖咗兩個星期，口語講到好嬲，唔知點寫成一封正式信。第39集用 Duck.ai（DuckDuckGo，duck.ai）：撳左側 New Chat 開新對話，寫明訂單、故障、要求同期限，撳藍色向上箭頭 Send，對住 GPT-6 Luna 回覆改訂單號同日期，抄落電郵再送。官方話唔使帳戶。示範訂單 DEMO-20261019、商戶「示範電器店」同藍牙耳機無聲都係虛構，無真實訂單、商戶、姓名、電郵。

Reel 一句講晒：Duck.ai｜投訴信／即出稿

你會學到

  • 點樣撳左側 New Chat，開一條新對話
  • 點樣寫訂單、故障、要求同期限，再撳藍色向上箭頭 Send
  • 點樣對住回覆改訂單號同日期，抄落電郵之前自己核對一次

開始前準備

  • 瀏覽器開 duck.ai。官方話唔使帳戶。登入同用量以你當日畫面為準
  • 手邊有訂單號、買咗咩、壞喺邊、想對方點做、幾多日內回覆。下面有示範句，可以照抄。真實訂單號、商戶、姓名、電話、電郵先改走
  • 知道回覆只係起稿。抄落電郵之後，事實同語氣自己讀一次，先至撳送出

可抄提示

示範句（虛構訂單同商戶，無真實姓名／電郵）

請用繁體中文寫一封正式投訴信：網購訂單 DEMO-20261019，商戶「示範電器店」，藍牙耳機開機無聲，客服已拖兩個星期；要求七日內退款或換貨；附主旨一行同正文。訂單號同商戶名係虛構，發出前請改。

3 步做法

  1. 撳 New Chat：開 duck.ai，撳左側 New Chat 開新對話。官方話唔使帳戶。本集第一步跟畫面名 New Chat，唔好留喺舊對話度改。

  2. 撳 Send：寫明訂單、故障、要求同期限，撳藍色向上箭頭 Send 送出。可以貼上面嗰句。示範訂單 DEMO-20261019、商戶「示範電器店」、藍牙耳機開機無聲、客服拖兩個星期、要求七日內退款或換貨，全部虛構。有真實訂單號、姓名、電話或者電郵，送出之前先改走。

  3. 抄定稿：對住 GPT-6 Luna 回覆改訂單號同日期，抄落電郵再送。主旨、訂單號、故障、要求、期限逐項對一次。AI 可能寫錯日期、語氣過重，或者將示範商戶名留低。示範稿唔好當已經寄出嘅信。

常見錯誤／注意事項

  • 唔核對就送出：訂單號、日期、故障、要求、期限逐項讀一次。AI 可能睇漏或者寫錯。
  • 當示範訂單係真實：DEMO-20261019、「示範電器店」、藍牙耳機無聲都係虛構。無真實商戶、姓名、電郵，唔好對號入座。
  • 貼真實個人資料：真實訂單號、地址、電話、電郵先改走，再撳 Send。
  • 搵唔到 Send：本集 contact 送出係藍色向上箭頭，掣名係 Send。當日畫面如果改名，跟你見到嘅送出掣。
  • 留喺舊對話：第一步撳 New Chat 開新對話，先寫今次投訴。
  • 模型名對唔上：contact 回覆標住 GPT-6 Luna。duck.ai 換模型嘅話，仍然係抄定稿再自己核對，唔好跟錯一個舊名。

示範訂單同商戶名純屬虛構。定稿只係方便起稿，正式發出前請自行核對事實同語氣。呢頁教你出信，唔係叫你轉發呢則片。
