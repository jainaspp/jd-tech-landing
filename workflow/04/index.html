你會得到咩

由大綱生成一疊可改嘅簡報卡，再匯出 PPT／PDF——適合堂課、內部短會、小型提案，唔使由零砌版面。

你需要咩

  • Gamma 帳戶（瀏覽器）
  • 一段已整理大綱（5–8 點更好）
  • 用量／credits 以你帳戶同官方說明為準；Reel 提到新戶約有 credits 額度，實際數字請睇帳戶顯示，唔好當永遠不變

步驟（跟 Reel + 官方建立流程）

  1. 登入 gamma.app，Dashboard 撳 Create New AI。
  2. 用 Paste 貼大綱（或 Generate／Import；課堂報告多數 Paste 最穩）→ 揀 Presentation → Generate。
  3. 逐頁改字；Theme 最後先換。改字通常唔使狂 regenerate。完成後匯出 PPT／PDF。

香港日常例子： 大學小組八分鐘講「香港食物浪費」。Paste：「1 問題規模 2 原因 3 超市／家居例子 4 三個學生行動 5 結語 CTA；對象同學；繁中；約 8 頁。」生成後刪無來源統計、出聲計時，超時就合併頁。

可抄 Prompt

主題：【簡報題目】
對象：【老闆／同學／客人】
時長：【例如 5 分鐘】
大綱：
【貼上 5–8 點】
請做成簡報結構，每頁一個重點，繁體中文，語氣【專業／輕鬆】，唔好捏造統計數字。
這一頁太長：請改成「標題＋最多 3 個要點」，保留原意，用繁體中文。
原文：
【貼上該頁文字】

常見錯誤

  • 空白 Generate 一個好闊題 → 改 Paste 自己大綱。
  • 亂 regenerate 食信用／額度 → 單頁微調、手改字。
  • 每頁好似文章 → 簡報要點到即止。

私隱提醒

唔好匯入未公開財務、客人名單到個人帳就隨意分享連結。數字要有來源。

簡報由「出得嚟」變成「講得出口」

生成後唔好直接投影。短流程：刪走你講唔出嘅術語同無來源統計；每頁只留一個訊息，要點超過三句就拆頁；自己計時講一次，超過時限就再收短；封面寫清場合同你名，尾頁放 Q&A。

Paste 模式通常比空白 Generate 更穩，因為內容主權喺你。Import 舊 PowerPoint 都得，但課堂報告多數「大綱貼上」更快。對外提案，把成本同利潤頁小心分享範圍；Theme 可以最後先換，避免中段不斷改風格浪費時間。

Reel 提醒：改字相對慳用量，亂 regenerate 先食信用。以你帳戶顯示嘅 credits／計劃限制為準，官方說明可能更新。
