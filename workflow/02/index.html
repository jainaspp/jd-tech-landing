你會得到咩

一頁長文／長網頁嘅「3 點重點」＋可複製去 WhatsApp／Notes／Notion 嘅摘要，唔使全文睇晒先做決定。

你需要咩

  • Microsoft 帳戶免費登入
  • 建議用 Microsoft Edge 開住個頁再用側欄 Copilot；或到 copilot.microsoft.com 貼網址
  • 官方指 Edge 入面用 Copilot 需登入；page context 開關見設定（以你帳戶為準）

步驟（跟 Reel）

  1. 開 Edge，或去 copilot.microsoft.com 免費登入。
  2. 開住要讀嘅網頁／貼網址，問：「用 3 點總結重點」（或撳 Create a Summary）。
  3. 複製重點去 WhatsApp／Notes／Notion；重要句返原文對一次。

香港日常例子： HR 助理十分鐘後要向主管講「混合辦公指引」。開住內聯網長文 → Copilot：「用書面中文：一句結論；五個員工要注意嘅規則；兩個要問 IT 嘅位。只根據呢頁。」再掃標題同粗體核對。

可抄 Prompt

請摘要呢一頁，用繁體中文：
1. 一句話結論
2. 5 個重點（每點 20 字內）
3. 1 個我應該自己再查嘅地方
只根據目前頁面，唔好用頁外知識補完。
將呢頁變成行動清單表格：要做咩｜邊類人負責｜有冇限期（冇就寫未提及）。

常見錯誤

  • 側欄好空泛 → 未允許讀取頁面脈絡，或開錯 tab。
  • 公司政策鎖功能 → 用個人檔案測，或只處理公開頁。
  • 摘要後唔筆記 → 對話一清就冇；即刻複製。

私隱提醒

唔好喺會被讀取 browsing context 時打開載有密碼、薪資、客人資料嘅分頁。摘要唔等於法律意見。

三步流程點樣變成日常

建議你固定用同一套追問，形成肌肉記憶：① Create a Summary 或「列五個重點」；②「邊啲係我今日要做」；③「邊句最可能過時或只係例子」。讀完政策頁、長教學文、產品比較文都可以同一套。

若答案講咗頁面冇嘅東西，多半係讀錯 tab，或者 page context 未開。去 Edge ⋯ → Copilot and AI，確認已開啟允許 Copilot 讀取網頁脈絡相關開關。公司電腦若鎖咗 Copilot 讀頁，唔好為咗方便就將內部文件貼去公用 AI。

關掉唔要嘅分頁再問，可以減少「答錯頁」同減少敏感脈絡被一併參考。PDF 喺 Edge 打開都可以用同一套摘要流程。摘要出嚟若有清單，試下即刻變成你日曆上嘅一格任務。
