香港可唔可以用？

OpenAI 官方「ChatGPT Supported Countries」名單冇 Hong Kong。官方仲寫明：喺名單以外嘅地區存取或者提供服務，帳戶可能會被封鎖或者暫停。

官方來源：ChatGPT Supported Countries（OpenAI Help Center）

本站唔會教任何 VPN、改地區或者帳戶繞路方法。官方名單冇香港，就請用官方支援香港嘅工具（見下面「香港官方可用嘅替代」）。

免費版限制

  • 定價頁寫 Free 計劃：用 GPT-5.6 Luna 嘅文字對話「Unlimited」，但要合理使用、受濫用防護限制
  • 上載檔案、生圖（官方寫較慢）、語音、Deep research、記憶全部係「Limited」
  • Free 嘅 GPT Instant 總 context window 係 27K，單次輸入上限大約 12 頁文字
  • 排程任務（Scheduled tasks）Free 冇

官方來源：ChatGPT Pricing（官方定價頁）。價錢同額度會變，以官方頁面為準；本站唔寫港幣換算。

廣東話／繁中支援

官方支援語言清單有「Chinese」，但冇分繁體／簡體，亦冇列 Cantonese（廣東話）。

官方來源：How to change your language setting in ChatGPT

香港人最啱用嚟做咩

  • ChatGPT 教學：粵語 workflow 模板
  • 香港 Prompt 庫：返工 WhatsApp／電郵
  • ChatGPT vs Gemini：香港人點揀

以上教學以官方可用地區為前提。

香港官方可用嘅替代

  • Gemini：網頁版同手機 app 官方名單都有香港（Where you can use the Gemini web app（Gemini Apps Help））
  • Microsoft Copilot：官方例外寫明「中國（香港除外）」（Supported regions and languages in Microsoft Copilot）
