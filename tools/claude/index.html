香港可唔可以用？

Anthropic 官方「Supported Regions Policy」入面，Claude.ai 可用嘅國家／地區名單冇 Hong Kong（商用 API 名單都冇）。

官方來源：Supported Regions Policy（Anthropic）

本站唔會教任何 VPN、改地區或者帳戶繞路方法。官方名單冇香港，就請用官方支援香港嘅工具（見下面「香港官方可用嘅替代」）。

免費版限制

  • 定價頁：Free $0，官方寫「Free for everyone」
  • 包括網頁、桌面、手機對話；搜尋網絡、建立檔案、執行程式碼；跨對話記憶；連接 apps 同工具；建立 Artifacts
  • Pro 寫「More usage」，即係 Free 用量較少；定價頁冇寫 Free 嘅具體次數

官方來源：Claude Pricing（官方定價頁）。價錢同額度會變，以官方頁面為準；本站唔寫港幣換算。

廣東話／繁中支援

官方介面語言清單（English、French、German、Hindi、Indonesian、Italian、Japanese、Korean、Portuguese (Brazilian)、Spanish）冇中文；官方話你可以用任何語言同 Claude 傾偈。開發者文件嘅多語言表現表只列 Chinese (Simplified)。

官方來源：How to use Claude in your preferred language、Multilingual support（Claude Docs）

香港人最啱用嚟做咩

  • Claude 教學：長文改稿同寫作
  • 香港 Prompt 庫：搵工（CV／求職信）

以上教學以官方可用地區為前提。

香港官方可用嘅替代

  • Gemini：網頁版同手機 app 官方名單都有香港（Where you can use the Gemini web app（Gemini Apps Help））
  • Microsoft Copilot：官方例外寫明「中國（香港除外）」（Supported regions and languages in Microsoft Copilot）

官方連結

  • 官網：claude.ai/
  • Help Center：support.claude.com/
  • 定價：claude.com/pricing
  • 開發者文件：platform.claude.com/docs/
