ChatGPT：第一次用到設定自訂指令

JD Tech｜粵語 AI 日更　·　免費工具 3 步實測

教你由開帳戶、打第一句，到設定「自訂指令」，令之後答覆都跟你平時做事方式。適合第一次用 ChatGPT 嘅上班族、學生同小生意老闆。

開始前要準備咩

  • 一個 OpenAI／ChatGPT 帳戶（免費計劃都可用自訂指令）
  • 電腦瀏覽器，或者手機 App（iOS／Android）都得
  • 免費同 Go 用戶：自訂指令最多約 1,500 字元；付費計劃上限較高。實際額度以官方說明為準

逐步操作

  1. 去 chatgpt.com 登入（或開手機 App）。
  2. 開新對話，用一句清楚要求試一次，例如叫佢改短一封 email。
  3. 入設定：
    • 網頁／桌面： Settings → Personalization → 打開 Enable customization → 喺 Custom Instructions 欄填寫。
    • 手機： Settings → Customize ChatGPT → 打開 Enable customization → 填 Custom Instructions。
  4. 建議分兩段寫清楚：你係邊類人／做咩工作；你想佢點樣回覆（語氣、長度、語言）。
  5. 儲存後開新對話測試一句；唔啱就返去改指令，唔使每句重講。

完整真實例子

場景： 銅鑼灣寫字樓行政，日日要回覆內部 email，想佢預設用簡潔書面中文。

你設嘅自訂指令（示意）： 「我係香港行政助理，日常處理會議安排同跟進。請用書面中文回覆，短句優先，列點清楚，唔好加我冇講過嘅承諾。」

你之後只打： 「幫我回覆同事，話週三下午會議改去 Google Meet，連結稍後再發。」

預期輸出（示意，非實時截圖）： 一封短 email 草稿，有改期原因、Meet 安排、同「連結稍後補發」一句；語氣得體、冇多餘客套。

第一次用可以只做兩件事：用預設對話改一封你真正要發嘅訊息；同設定一段唔超過半屏嘅自訂指令。唔使一次學完外掛、語音、畫圖。等你覺得「唔使每次解釋我係邊個」之後，先再加其他功能。

同同事分享做法時，只分享你嘅指令模板，唔好分享載有公司內部稱呼、未公開項目名嘅對話截圖。

可抄 Prompt

你係一個溝通得體嘅香港上班族。
幫我將以下訊息改成【客氣／直接】語氣，保留所有日期同人名，唔好加新承諾。
長度【約 80 字／150 字內】，用書面中文。
原文：
【貼上你嘅草稿】
角色：我係【職位，例如中小企老闆／大學生】。
回覆時請：用【廣東話口語／書面中文】、先結論後細節、需要時用列點。
唔好捏造數字、法例或我冇提供嘅資料。
幫我列 3 個版本嘅回覆給【對象】：
目的：【例如婉拒加班／追貨期】
限制：【例如唔可以承諾折扣】
每個版本 60 字內。
背景：【兩句事實】

常見錯誤＋點樣改

  • 指令寫到好長又空： 改做「我做咩＋想點答＋禁止咩」三句就夠。
  • 舊對話仍然好官腔： 自訂指令主要影響之後對話；開新 chat 再試，或者清空唔想保留嘅舊對話。
  • 敏感資料寫入指令： 唔好放身份證、密碼、客人電話；用「客人 A」代替。
  • 把自訂指令當成一次性 prompt： 指令應該係穩定偏好；單一任務細節仍要喺該則對話講清楚。
  • 中英夾雜指令令輸出失控： 指示用邊種語言出答案，寫死一句更穩。

私隱／核對提醒

自訂指令會影響之後多數對話。官方說明亦提到相關使用資料可能用於改進模型（你可喺帳戶設定檢視資料選項）。交畀老闆或客人前，自己讀一次；價錢、日期、法例一定人手核對。

多一步：令指令真係日日用得着

寫自訂指令時，唔好寫人生傳記。夠用嘅結構係：

  1. 身份同場景： 例如「香港中小企行政，日文 email 同內部通知為主」。
  2. 輸出習慣： 「先結論、後細節、可以列點、書面中文、少形容詞」。
  3. 紅線： 「唔好發明法律意見、唔好承諾退款、唔好改我提供嘅日期」。

設完之後，用同一類真實工作連續試三日：改 email、整理待辦、寫會議邀請。發覺佢成日加客套，就喺指令加一句「刪走冇資訊量嘅客套開場」。發覺太短，就加「每封至少交代目的、行動、期限三樣」。

若你同屋企人共用電腦，記得用完登出，或者分開瀏覽器設定檔，避免對話紀錄混埋。

今日就可以試

打開 ChatGPT，用你信箱入面一封未回嘅訊息做材料：先唔設指令改一版，再設自訂指令後開新對話改同一封，對比邊版少改動。滿意就留低指令，唔滿意只改三句再試。成個過程十五分鐘內做得完。
