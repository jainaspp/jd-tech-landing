CapCut：短片自動字幕

JD Tech｜粵語 AI 日更　·　免費工具 3 步實測

最後更新：2026-09-24

教你喺 CapCut 用 Auto Captions／Recognise Subtitles 幫短片出字幕，再改錯字同樣式。適合要出 Reels／Shorts 嘅小生意同學生。

開始前要準備咩

  • CapCut 帳戶；可用 手機 App、桌面版 或 Web（capcut.com）
  • 一段已拍好、人聲較清楚嘅短片（盡量少背景音樂遮住對白）
  • 自動字幕核心功能各平台都有；進階如講者區分、批次匯出字幕檔等可能因地區／版本而異——以官方說明為準

逐步操作

（以下以官方文件中嘅 Web／Desktop／Mobile 流程為準，用字或係 Auto Captions／Recognise。）

  1. 匯入影片，開新專案。
  2. 進入字幕功能：
    • Web： 左側 Captions → Auto Captions → Recognise → 揀語言 → Generate；
    • Desktop： 左欄 Captions → Auto Captions → 揀音訊來源同語言 → Generate；
    • Mobile： 底欄 Captions → Auto Captions → 確認語言 → Generate。
  3. 點每一句改錯字（粵語口語、店名、價錢最常錯）。
  4. 調整樣式：字體、大細、位置（避開臉同按鈕區）。
  5. 預覽全片再匯出；官方建議改完一定開聲對一次。

完整真實例子

場景： 深水埗飾品檔要出 20 秒「新品三件套」IG Reel，老闆娘用廣東話口播。

輸入： 直向影片入 CapCut → Auto Captions 語言揀中文／粵語相關選項（以 App 列表為準）→ Generate。

預期輸出（示意）： 時間軸上出現一句句字幕；可能把「耳線」認成近音字。你改啱店名同「$68」後，放大字幕、放到下方安全區，就可以出片。

出片節奏可以係：先定 15–30 秒腳本 → 拍口播 → 自動字幕 → 改關鍵錯字 → 加字幕樣式 → 最後先加貼紙同轉场。倒轉次序好易令字幕被蓋住。

同一條片要出 IG 同小紅書，可以複製專案後只改封面字同比例，唔使重跑字幕。

可抄 Prompt

（CapCut 內主要係按鈕操作；若你先用 AI 寫口播稿，可用：）

用廣東話口語寫 20 秒口播稿，主題【產品／活動】。
結構：フック一句 → 2 個賣點 → 一句行動呼喚。
全稿 75 字內，唔好加我冇提供嘅價錢。
資料：【貼上重點】
將以下口播稿斷成適合字幕嘅短句（每句不超過 12 字），保留原意：
【貼上口播】
檢查字幕有冇錯：店名、日期、金額。列出可疑項同建議修正。
字幕：
【貼上】

常見錯誤＋點樣改

  • 字幕錯超多： 官方建議靜音背景音樂後再 Generate；嘈雜環境可重錄人聲軌。
  • 一句太長： Web／Desktop 可喺時間軸分割字幕再改（例如剪刀或快捷鍵；以你版本為準）。
  • 認錯語言： 重新跑 Auto Captions 並揀對語言。
  • 字幕遮住人臉或按鈕： 移去下方或上方安全區，並檢查不同手機比例。
  • 改完文字唔對時間軸： 長句分割後檢查入出點，避免字仲喺、人已講完。

私隱／核對提醒

出街片唔好露出其他人身份證、學生證、電腦畫面密碼。自動字幕唔等於精準文本；涉及價錢、醫療、法律聲稱一定改啱先發。

字幕質素點樣穩陣上嚟

自動字幕對口音、專有名詞、價錢最弱。拍片時可先行：

  • 口播稍慢、對住咪高峰
  • 音樂軌音量低過人聲，或者後期先出字幕再叠音樂
  • 店名、系列名用畫面大字重複一次，字幕錯都有畫面撐

改字幕時優先改：金額、日期、品牌名、叫人點做嘅一句。樣式方面，白字黑邊或半透明底喺街景片較易讀。

一條 Reel 唔使字字完美，但「錯價」同「錯電話」會直接影響生意，呢兩類錯零容忍。匯出前用耳機聽全文一次，睇字幕同嘴型係咪差太遠。

今日就可以試

用手機拍一段十五秒、只有你自己講嘅口播（介紹你正在做嘅一件事），入 CapCut 跑 Auto Captions，只改專有名詞同價錢類錯字，調樣式後匯出。完成即係你嘅第一條「可出街」字幕流程。

另外記低：字幕樣式唔使每條片都不同；固定兩款（淺底深字／深底淺字）反而更似品牌。音樂有歌詞時，小心同字幕搶視線，可減音樂或乾脆口播為主。

公眾人物或路人入鏡要小心；唔肯定就裁走畫面，字幕都一併删相關句。 養成「先小範圍實測、再放大到正式場合」嘅次序，出錯成本會低好多。

先用非機密材料練習，確認流程同用字，先代入真正工作內容。

若口播有中英夾雜，生成後優先改品牌英文名同價錢，其餘口語錯字可第二輪再清。

匯出前用耳機聽全文一次，確認字幕同嘴型唔會差到出戲。
