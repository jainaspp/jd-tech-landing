Gamma：大綱變簡報

JD Tech｜粵語 AI 日更　·　免費工具 3 步實測

教你用 Gamma 將大綱或筆記變成可編輯簡報草稿，再改主題同文字。適合要趕堂課報告、內部短講、小型提案嘅人。

開始前要準備咩

  • Gamma 帳戶，登入後到 Dashboard
  • 電腦瀏覽器
  • 一段已整理大綱（愈具體愈好）。免費／付費用量同一次改多頁 AI 功能或有分別——以帳戶同官方說明為準

逐步操作

  1. 喺 Dashboard 撳 Create New AI。
  2. 三個模式揀一個：
    • Generate：只得主題，畀 AI 起草；
    • Paste：貼你已有大綱／筆記（最適合課堂）；
    • Import：上載現有檔或貼連結再轉成 Gamma。
  3. 揀 Presentation，按提示設定語言、細節程度、風格等（畫面有進階選項可再收窄）。
  4. 預覽大綱後確認 Generate，等卡片（投影片）生成。
  5. 逐頁改：可撳頁面左上角 sparkle（AI）微調單頁；改主題用右上 Theme。講稿自己再讀一次出聲。

完整真實例子

場景： 大學小組下星期一要講「香港食物浪費」八分鐘。

輸入（Paste 示意）： 「1 問題有幾大 2 常見原因 3 超市同家居兩例子 4 三個學生做得到嘅行動 5 結語一句 call to action。對象：同學。語氣：認真但唔說教。語言：繁體中文。約 8 頁。」

預期輸出（示意）： 一疊有標題同要點嘅簡報卡，或會配圖；你要刪走誇張統計、補上你組真正搵到嘅來源，再調頁序。

小組分工建議：一人負責大綱事實、一人負責 Gamma 起稿、一人負責出聲計時。唔好三人同時喺同一份亂改風格。

若老師要求指定頁數，喺提示寫明「不多於 X 頁」；生成後仍超頁就合併相似頁，而唔係細字硬塞。

可抄 Prompt

主題：【簡報題目】
對象：【例如老闆／同學／客人】
時長：【例如 5 分鐘】
大綱：
【貼上 5–8 點】
請做成簡報結構，每頁一個重點，繁體中文，語氣【專業／輕鬆】，唔好捏造統計數字。
將以下筆記轉成簡報大綱（只保留可講出口嘅要點，刪廢話）：
【貼上筆記】
這一頁太長：請改成「標題＋最多 3 個要點」，保留原意，用繁體中文。
原文：
【貼上該頁文字】

常見錯誤＋點樣改

  • 一開始就 Generate 一個好闊主題： 改用 Paste 自己大綱，內容先控得到。
  • 圖太多搶戲： 生成時可選少圖／placeholder（官方有 Don’t add images／Image placeholders 等選項），或生成後刪圖。
  • AI 改完意思飄咗： 用 View Source Prompt 睇返當初提示；單頁用 sparkle 微調，重要數據手打。
  • 每頁段落好似文章： 簡報要點到即止；細節留口講或講者註。
  • 忽視對象： 同一題畀教授同畀同學，用詞同深度應不同，提示要寫明。

私隱／核對提醒

唔好匯入載有未公開財務、客人名單嘅檔案到個人帳戶就隨意分享連結。簡報內數字、引文要有來源；對外發表前刪草稿備註。

簡報由「出得嚟」變成「講得出口」

生成後唔好直接投影。用呢個短流程：

  1. 刪走你講唔出嘅術語同無來源統計。
  2. 每頁只留一個訊息；要點超過三句就拆頁。
  3. 自己計時講一次，超過時限就再叫 AI 收短該頁。
  4. 封面寫清場合同你名；尾頁放聯絡或 Q&A。

Paste 模式通常比空白 Generate 更穩，因為內容主權喺你。Import 舊 PowerPoint 都得，但課堂報告多數「大綱貼上」更快。

對外提案，把成本同利潤頁設為講嘅時候先 overlay，唔好連公開連結一齊傳到唔相關嘅人。主題（Theme）可以最後先換，避免中段不斷改風格浪費時間。

今日就可以試

把你下一次要講嘅題目写成七點大綱，用 Paste 模式生成簡報。自己站起來計時講三分鐘：邊頁講唔完就删，邊頁無嘢講就合併。改到口順，先諗動畫同配圖。

另外記低：生成後先改文字事實，再換 Theme，最後先理圖片。次序倒轉好易花半日喺美化，內容錯誤仍然喺。對外簡報記得删講者備註入面嘅內部吐槽。

如果你嘅大綱本身係英文，亦可要求輸出繁中簡報，但專有名詞保留原文，避免翻譯到唔認得。 養成「先小範圍實測、再放大到正式場合」嘅次序，出錯成本會低好多。

先用非機密材料練習，確認流程同用字，先代入真正工作內容。

課堂報告可以用「大綱 Paste → 生成 → 出聲計時 → 刪頁」四步做完；美化留到最後半小時就夠。

對外提案記得刪講者備註入面嘅內部吐槽，避免投屏時尷尬。
