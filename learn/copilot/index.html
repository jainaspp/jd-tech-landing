Copilot：長網頁 3 步變重點

JD Tech｜粵語 AI 日更　·　免費工具 3 步實測

最後更新：2026-09-24

教你喺 Microsoft Edge 用內建 Copilot，對住而家開緊嘅長網頁或 PDF，三步拎摘要同行動項。適合要快讀政策、教學文、產品說明嘅人。

開始前要準備咩

  • 安裝／開啟 Microsoft Edge
  • 用個人 Microsoft 帳戶登入 Edge（官方指需登入先用 Copilot in Edge）
  • 電腦較穩；Edge 手機版亦有 Copilot，但側欄體驗以桌面為準
  • 免費可用頁面摘要類功能；部分語音／Vision 能力或需 Microsoft 365 等方案——以你帳戶實際顯示同官方說明為準

逐步操作

  1. 用 Edge 打開你要讀嘅網頁或 PDF。
  2. 撳視窗右上角 Copilot 圖示，打開側欄。
  3. 三選一開始：
    • 撳 Create a Summary 直接要摘要；或
    • 打字：「用繁體中文列 5 個重點同 1 個結論」；或
    • 揀側欄建議嘅相關提示。
  4. 若摘要答唔到頁面內容：去 Edge ⋯ → Copilot and AI，確認已開啟允許 Copilot 讀取網頁脈絡（官方用字約為允許讀取 context clues／page content）相關開關。
  5. 追問「邊啲係行動項」「邊句最可能過時」，再自己點返原文核對。

完整真實例子

場景： 人力資源助理要讀一長篇「混合辦公指引」內聯網文，十分鐘後要同主管講重點。

輸入： 開住該頁 → Copilot →「用書面中文：一句結論；五個員工要注意嘅規則；兩個要問 IT 嘅位。只根據呢頁，唔好加其他公司做法。」

預期輸出（示意）： 短摘要＋五點（例如預約座位、核心時段、設備申請）；若頁面冇寫罰則，不應出現罰則細節。你再掃標題同粗體核對一次就交得。

讀完記得把有用重點貼去你自己嘅筆記，而唔係只留喺側欄對話。Edge 對話可能會清，你自己嘅待辦先係執行源。

遇到要翻譯又要摘要，可以分兩步：先中文重點，再問「呢五點有冇同英文標題意思衝突」。

可抄 Prompt

請摘要呢一頁，用繁體中文：
1. 一句話結論
2. 5 個重點（每點 20 字內）
3. 1 個我應該自己再查嘅地方
只根據目前頁面，唔好用頁外知識補完。
將呢頁變成行動清單表格：要做咩｜邊類人負責｜有冇限期（冇就寫未提及）。
我係【職位】。用 mid-career 聽得明嘅比喻，解釋呢頁最重要嘅 3 個概念，每個概念兩句。

常見錯誤＋點樣改

  • 側欄答得好空泛： 多數係未允許讀取頁面脈絡，或開錯 tab；開準頁再問「summarize this page」。
  • 公司政策鎖咗功能： 工作帳戶可能被管理員關閉 page context；改用個人檔案測試，或改手動複製公開段落去對話（注意機密）。
  • 一次開好多 tab： 官方指回應可能用到開緊嘅分頁資訊；敏感分頁先關。
  • 摘要後唔截圖唔筆記： 對話一清就冇；即刻複製去自己文件。
  • 用工作檔案測個人 Copilot： 注意公司政策同保密條款。

私隱／核對提醒

唔好喺會被用作 browsing context 嘅情況下打開載有密碼、薪資、客人資料嘅分頁。可隨時喺 Copilot and AI 設定關閉讀取網頁脈絡。摘要唔等於法律／合規意見，重要規定返原文。

三步流程點樣變成日常

建議你固定用同一套追問，形成肌肉記憶：

  1. Create a Summary 或「列五個重點」。
  2. 「邊啲係我今日要做」。
  3. 「邊句最可能過時或只係例子」。

讀完政策頁、長教學文、產品比較文都可以同一套。若答案講咗頁面冇嘅東西，多半係讀錯 tab，或者 page context 未開。

公司電腦若鎖咗 Copilot 讀頁，唔好為咗方便就將內部文件貼去公用 AI；改用公司批准嘅工具，或者只摘要已公開資訊。個人學習用個人 Microsoft 帳戶同個人檔案會較清楚。

關掉唔要嘅分頁再問，可以減少「答錯頁」同減少敏感脈絡被一併參考。

今日就可以試

用 Edge 打開一篇你收藏咗又一直未讀嘅長文，開 Copilot 撳 Create a Summary，再用「五個重點＋一個行動」追問。把結果貼去備忘錄，標註邊句已核對、邊句未核對，呢個標註習慣比工具本身更值錢。

另外記低：PDF 喺 Edge 打開都可以用同一套摘要流程。若公司政策唔准用側欄 AI，就改用已批准工具，或者只處理公開網頁，唔好硬來。

摘要出嚟若有清單，試下即刻變成你日曆上嘅一格任務，工具先同行動接埋。 養成「先小範圍實測、再放大到正式場合」嘅次序，出錯成本會低好多。
